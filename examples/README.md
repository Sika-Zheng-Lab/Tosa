# Example data for Tosa

This directory contains small synthetic BAM/CRAM and GTF files to try out Tosa.
The files are generated by `cargo run --example generate_example_bam`.

## Input files

| File | Description |
|------|-------------|
| `example.bam` / `example.bam.bai` | 26-read synthetic BAM on `chr1` with 2 splice junctions |
| `example.cram` / `example.cram.crai` | Same data in CRAM format |
| `annotation.gtf` | GTF annotation with 3 exons and 2 introns on `chr1` |
| `barcodes.tsv` | Cell barcodes for single-cell mode (`AAAA-1`, `BBBB-1`, `CCCC-1`) |

### Annotation layout

```text
chr1:  ===exon1===  ---intron1---  ===exon2===  ---intron2---  ===exon3===
       1000-1200    1201-1499      1500-1700    1701-1999      2000-2300
```

## Pre-generated output

The `output/` directory contains reference outputs so you can see the expected format
without running Tosa yourself.

### Bulk mode (unstranded)

Command: `tosa bulk example.bam output/bulk`

| File | Description |
|------|-------------|
| `bulk_junction.tsv.gz` | Junction counts (2 junctions, strand `.`) |

### Bulk mode with GTF (unstranded)

Command: `tosa bulk -g annotation.gtf example.bam output/bulk_gtf`

| File | Description |
|------|-------------|
| `bulk_gtf_junction.tsv.gz` | Junction counts |
| `bulk_gtf_boundary.tsv.gz` | Boundary counts (4 boundaries: 5p/3p × 2 introns) |

### Bulk mode with XS strand

Command: `tosa bulk -s XS example.bam output/bulk_xs`

| File | Description |
|------|-------------|
| `bulk_xs_junction.tsv.gz` | Strand-split junction counts (`+` / `-`) |

### Bulk mode with XS strand + GTF

Command: `tosa bulk -s XS -g annotation.gtf example.bam output/bulk_xs_gtf`

| File | Description |
|------|-------------|
| `bulk_xs_gtf_junction.tsv.gz` | Strand-split junction counts |
| `bulk_xs_gtf_boundary.tsv.gz` | Strand-split boundary counts |

### Single-cell mode

Command: `tosa single -c barcodes.tsv example.bam output/single`

| File | Description |
|------|-------------|
| `single_matrix.mtx.gz` | MatrixMarket sparse matrix (junctions × barcodes) |
| `single_barcodes.tsv.gz` | Cell barcode list |
| `single_features.tsv.gz` | Junction feature list |
| `single_junction_barcodes.tsv.gz` | Detailed per-barcode junction counts |

### Single-cell mode with GTF

Command: `tosa single -c barcodes.tsv -g annotation.gtf example.bam output/single_gtf`

| File | Description |
|------|-------------|
| `single_gtf_matrix.mtx.gz` | Junction MatrixMarket sparse matrix |
| `single_gtf_barcodes.tsv.gz` | Cell barcode list |
| `single_gtf_features.tsv.gz` | Junction feature list |
| `single_gtf_junction_barcodes.tsv.gz` | Detailed per-barcode junction counts |
| `single_gtf_boundary_matrix.mtx.gz` | Boundary MatrixMarket sparse matrix |
| `single_gtf_boundary_barcodes.tsv.gz` | Cell barcode list (boundary) |
| `single_gtf_boundary_features.tsv.gz` | Boundary feature list |
| `single_gtf_boundary_barcodes_detail.tsv.gz` | Detailed per-barcode boundary counts |

## Quick start

```bash
# Count junction reads (bulk mode)
tosa bulk examples/example.bam output_example

# Count junction + boundary reads with GTF annotation
tosa bulk -g examples/annotation.gtf examples/example.bam output_example

# Strand-specific counting (XS tag mode)
tosa bulk -s XS examples/example.bam output_example_xs

# Single-cell mode
tosa single -c examples/barcodes.tsv examples/example.bam output_example_sc

# Use CRAM file (no reference FASTA needed)
tosa bulk examples/example.cram output_example_cram

# CRAM with GTF annotation
tosa bulk -g examples/annotation.gtf examples/example.cram output_example_cram_gtf
```

See the project [README](../README.md) for full usage details.
